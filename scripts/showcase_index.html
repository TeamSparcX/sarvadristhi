Why investigators should pick Sarvadristhi

Other tools show you a video. Sarvadristhi shows you where every frame came from, where the sources disagree, and how anyone can check it.

Any brand

Reads the bytes, not the label

Native parsers for Hikvision, Dahua / CP Plus and Honeywell, in H.264 and H.265. A universal path carves raw video and reads the burned-in camera and clock for every other recorder, so one tool covers what used to need five.

Proof

Every claim has its evidence

Formatted and overwritten footage is recovered and marked by how strong it is. Exports are matched frame by frame against the recorder. Clocks are measured, never trusted. A hash-chained custody log records every step.

Honest

Built to be checked

A signed replay capsule lets anyone rebuild every clip without our code. AI output stays a lead until an examiner accepts it, and limits are printed on every screen. The court report carries the Section 63(4) data sheet.

Run it yourself

  • Windows 11 laptop with an NVIDIA RTX 4050 GPU (6 GB, CUDA 12.8)
  • Python 3.12, FFmpeg, Tesseract, Ollama with Qwen3-VL 4B: installed by scripts\setup_windows.ps1
  • Then scripts\run_demo.ps1 and open http://127.0.0.1:8770: everything stays on the machine
  • No GPU? The Docker image runs on CPU (much slower for AI analysis)
